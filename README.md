# RoughSilo

Simplifies data backup and restore processes for small to medium-sized businesses with multiple branch offices.

The key benefits of using RoughSilo include:

- Simplifies data backup and restore
- processes for small to medium-sized
- businesses with multiple branch offices

- Simplifies data backup and restore

- businesses with multiple branch offices

## Technology Stack

- python
- Standard library, minimal dependencies
- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/RoughSilo.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Runtime options can be set in the config file or overridden per call. The most commonly changed values are:
- **timeout**: how long operations may run before failing
- **retries**: how many times a failed operation is re-attempted
- **cache**: where temporary results are stored
